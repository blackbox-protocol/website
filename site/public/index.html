Verification

Change one byte and verification fails.

A receipt is signed and verified, then altered by a single byte and verified again. The failure names the check that caught it.

blackbox — verify
$ blackbox sign --payload deploy-action.json --key signer.key --issuer deploy-signer --counter 1 --bundle-version 0 --key-version 0 --nonce 00112233445566778899aabbccddeeff --timestamp 2026-06-04T00:00:00Z --output receipts/deploy.cose
signed: wrote 245 bytes to receipts/deploy.cose

$ blackbox verify receipts/deploy.cose --bundle anchors.json --signer-key-id deploy-signer:0
composite: PASS
